# Portals do nothing during a Run

A Run stays in its Run dimension, which only changes at Prestige (pack ADR-0008). The Run start snapshot and the Prestige sweep only cover the Run area, so anything taken through a portal would be stranded and never converted to EMC. `run/RunDimensionLock` therefore closes every portal while the world has a Run (`RunAreas.current` is present). Before the first Run, portals work as usual.

- **Lighting a frame fails:** `BlockEvent.PortalSpawnEvent` is cancelled. It is posted by `BaseFireBlock.onPlace`, so it covers flint and steel, fire charges, dispensers, lava and lightning. The fire still lands in the frame and burns out.
- **Portal blocks don't move anything:** every portal (Nether portal, End portal, End gateway) goes through `Entity.handlePortal`, which only runs for an entity with a `portalProcess` (set while it stands in a portal block) and then calls `changeDimension`, which posts `EntityTravelToDimensionEvent`. An End gateway's jump within the End posts it too, with the same dimension. The handler cancels the event when the entity has a portal process, and drops that process, so an entity still standing in the portal waits the full portal delay before it is stopped again. A player sees "Portals do nothing during a Run" on the action bar.
- **Other teleports pass:** `/tp`, `/execute in ... run tp` and the Prestige teleport have no portal process. `RunAreas.teleport` drops the player's portal process first, so Prestige still moves a player who is standing in a portal, from any dimension.
- **Cost of cancelling late:** `handlePortal` works out the destination before `changeDimension`, so a Nether portal trip that is stopped may still load the Nether chunks around its destination and build the exit portal there. Portal blocks can't be lit during a Run, so in practice only portals left from before the first Run, or End portals and gateways, get this far.
- **Known gap, End credits:** in the End, a player who hasn't seen the credits and steps into the exit portal is removed by `showEndCredits()` without going through `changeDimension`, so the lock can't stop it. Runs are overworld-only for now; this matters once End Runs arrive (ADR-0008).
- **Tests:** `RunDimensionGameTests` lights the `nether_portal_frame` template (the helper's y = 0 is the floor, so the template's bottom layer is at helper y = 1) and stands a pig in a Nether portal and in an End portal, both during a Run and (as a control) with no Run, and checks the Prestige teleport brings back a player standing in a portal in the Nether.
